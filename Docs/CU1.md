CU1 : Ingreso de moto

- Un cliente NUEVO entra y solicita un service para una motoclicleta NO INGRESADA

1. Se ingresan en el sistema los datos de cliente: Nombre y contacto
2. Se ingresa en el sistema el vehiculo y sus datos: Marca, modelo, cilindrada
3. Se ingresa en el sistema el tipo inicial de mantenimiento: service basico, full, cambio especifico de componente o mantenimiento correctivo.
4. El sistema guarda la orden, vinculando el contacto del cliente con la moto y su estado de service.
5. El sistema calcula en cuanto tiempo el cliente podra corroborar su estado.
6. Se muestra por pantalla el correcto guardado de la orden y su tiempo estimado.
